What you're actually learning

Every stat you already argue about is a programming concept wearing cleats:

• The player row = an object — keys and values bundled as one thing ({name: "Mahomes", team: "KC", pass: 4500})
• The league table = an array of objects — and every fantasy app you've used is exactly that, with a nicer paint job
• Sort by total = a sort function with custom logic — the same move that powers every leaderboard you've ever seen
• Export JSON = turning live data into the file format the whole block runs on (urban-dictionary/json_explained.md is the primer)

Open db-bridge.js (this folder) — the whole engine is one readable file. It's the math you already do, visible.

The database rung — where this gets real

This table saves to your browser (localStorage). The next rung is a REAL database: schema.sql (this folder) is the SQL that creates the same table in Supabase — the block's stat-tracker backend (ADR-006). Same data, now shareable with the whole league: every brother's picks, one source of truth.

SQL — that's the language databases speak. "SELECT * FROM players ORDER BY total DESC" is literally "show me the table, best first." You already think in these queries at halftime. SQL just writes it down.
