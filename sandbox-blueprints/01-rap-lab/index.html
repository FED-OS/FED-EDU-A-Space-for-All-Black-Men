🎤 Rap Lab

You already write bars. This lab turns that skill into code skill — one rhyme at a time.

Write a bar, get the rhyme tech readout

Type your bar below. The lab counts syllables, finds the last word, and pulls rhymes from the same sound family — the same way your ear does it, but with receipts you can see.

The verse builder

Paste a whole verse (16 bars, one per line). The lab counts bars, syllables per bar, flags bars that run long, and saves your draft on THIS device — nothing leaves your phone (SECURITY.md rules).

What you're actually learning

Every feature here is a real programming concept wearing street clothes:

• Syllable counting = string processing + regex (the same tech behind every text analyzer you've ever seen)
• Rhyme matching = data structures — matching words by their ENDING sound is how autocomplete and search engines work
• Verse analysis = arrays + loops — a verse is just an array of bars, and the report is a loop over that array

Open audio-core.js (this folder) — the whole lab is one readable file. Read it after you use it. It's the same skill you already have: hearing structure in bars, except now you can see the code doing the hearing.
