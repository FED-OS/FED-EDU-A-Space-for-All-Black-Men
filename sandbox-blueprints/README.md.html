SANDBOX BLUEPRINTS — READY-TO-FORK PROJECTS

Every brother learns faster when the first project is already half-built. These blueprints are the half-built house: fork one, make it yours, ship it. Four doors in — pick the one that matches what you already love.

THE FOUR BLUEPRINTS

01-rap-lab — for the brothers who live in the music. A beat-and-bar lab: write bars, tap the beat, hear it back. Audio in the browser, your phone is the studio. Files: index.html, audio-core.js, project-manifest.json.

02-football-stats — for the brothers who live in the game. A stat tracker for players and squads: log buckets, boards, minutes; see who's really hooping. It's a real database app — SQL in the browser. Files: index.html, db-bridge.js, schema.sql.

03-media-fx-clipper — for the brothers with the eye. Background wipe for photos and thumbnails: run the Python script, get a clean cutout for the hustle pages. Files: index.html, bg-remover.py.

04-streamer-tools — for the brothers going live. An alert wall test bench, a Streamlabs/Twitch alert bot in Node, and a trend scraper that tells you what the internet is watching right now. Files: index.html, stream-alert-bot.js, trend-scraper.py, config.example.json.

HOW TO FORK ONE

Hit Fork on the repo, open the blueprint folder in the GitHub web editor (the pencil works on a phone), change anything you want, commit. That's the whole move. The wiki page Fork-Your-First-Repo walks it step by step with pictures.

Forked and shipped? Post it in the Community Boards showcase vault with a vouch — a shipped blueprint rung is 15 raffle tickets in the economy, the biggest single ticket item there is. Real projects, real tickets.

THE FED-EDU STARTER LOADOUT

This is the software stack that goes on every raffle machine and every refurb build before it ships. It's also the stack the courses assume — if your rig has these, every guide in this repo works on it:

  • A browser — Firefox or Chrome, current version.
  • A text editor — VS Code if the machine can carry it, Notepad++ if it can't.
  • Python 3 — python.org download, check the box that adds it to PATH.
  • Node.js LTS — nodejs.org download. The alert bot and any JS tooling runs on it.
  • The first-guide bookmark — the playground at courses-and-guides/02-real-life-minecraft/index.html, bookmarked so the first boot lands somewhere with a next step.

That's the whole loadout. No paid software, no giant installs — a scrap PC carries it fine, and the safe-shipping checklist for the raffle machines installs exactly this list before any box leaves the block.

THE RUNG SYSTEM

Each blueprint has rungs — small, shippable upgrades. Rung one is "fork it and change the title." Rung five is a different app. The rungs are written out in each blueprint: the Rap Lab keeps its full ladder in 01-rap-lab/project-manifest.json, and 02/03/04 lay their rungs out right in their index.html pages ("Take it further" — the rung section near the bottom). Ship a rung, post the receipt, claim the tickets. Nobody jumps from zero to senior engineer — but anybody can climb rungs, because every rung is small enough to finish tonight.
