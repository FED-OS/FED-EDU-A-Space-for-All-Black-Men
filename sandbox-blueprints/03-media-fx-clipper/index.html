What you're actually learning

Every filter you've ever picked is a loop over pixels — the same loop pattern as the Rap Lab's verse analyzer and the stats table's ranking. One concept, three costumes:

• Hustle tint = blend math — mix each pixel toward the green by X% (the slider IS the X)
• Grayscale = the luminosity formula — 0.3R + 0.6G + 0.1B, the same weights every editor uses, because that's how eyes weigh color
• Contrast punch = pushing values away from mid-gray — the same math behind every "vivid" toggle
• VHS drift = offsetting color channels a few pixels — real glitch effects are exactly this, just fancier offsets

The FX rack runs in THIS page. The PC rung is bg-remover.py (this folder) — Python removing backgrounds offline. Two languages, one skill: you already have the eye, now you collect the tools.
