SAFE SHIPPING CHECKLIST — PHYSICAL RAFFLE MACHINES

Every refurb tower, laptop, and phone kit that leaves the FED-EDU block goes through this checklist. No exceptions. The machine is the mission — a leaked address kills trust and puts brothers in danger. This paper is the law on how addresses move.

Read it once before your first shipment. Print it. Tape it to the wall next to your packing tape. Run it line by line, every box, every time.

THE ONE LAW

A brother's home address NEVER touches the public repo, the boards, or any issue.

Not in a commit. Not in a DM on the boards. Not in a comment. Not "just for a second." The repo is public. The whole world can read it. If an address lands in a commit, it is in the git history FOREVER — deleting the file does not delete the history. The only address channel that exists is fed-comm-dm, the custom DM system, and that system moves the address encrypted and deletes it after the label prints. That's the whole law. Everything below is just how we keep it.

BEFORE YOU SHIP — THE SENDER'S LINES

1. THE WINNER VERIFICATION

  • [ ] Winner confirmed by re-running the public raffle math — winner, pool size, and seed posted in the raffle results file. If the math does not re-run, the draw is void and you re-run with a new public seed.
  • [ ] Winner's entry in hustle-index/members/ matches the ticket count used in the draw. Receipts posted, vouches standing, no open integrity flags.
  • [ ] Winner is not the same brother who won a machine in the last 12 months — the one-machine-a-year rule from earn-tickets.json. The engine holds the history; check it, don't guess it.
  • [ ] Winner is 18 or older. If under 18, EVERYTHING goes to the guardian line below. No exceptions, not even "he's basically 18." Basically-18 is not 18.

2. THE ADDRESS HANDOFF — FED-COMM-DM ONLY

  • [ ] Address request sent through fed-comm-dm encrypted messaging. The winner gets the request through the same channel. If a brother posts his address ANYWHERE public — issue, board, comment — you delete the post immediately, tell him why in DM, and treat the posted address as burned. A new one gets requested. The posted one never gets used.
  • [ ] Address received inside the DM system only. It was never in your email, never in a text, never in a file on the repo.
  • [ ] You confirmed the shipping name is the name that can receive mail at that address. Some brothers ship to a mama's house, a barbershop, a library, a church — the name on the label must match the door that opens.

3. THE LABEL

  • [ ] Label printed from the fed-comm-dm address pass-through. Printed ONCE.
  • [ ] Return address is the FED-EDU block PO box or the hub drop-off point — NEVER your home address. The sender's home address is as protected as the winner's.
  • [ ] After the label prints, the address is deleted from the DM system. The system does this itself — verify the deletion actually happened before you close the conversation. If it didn't delete, flag it to the help desk.
  • [ ] The label PDF or screenshot is deleted from your machine after printing. Not in the trash folder — deleted. Shift+Delete on Windows, not just Delete. Empty the trash after.

4. THE MACHINE

  • [ ] Storage drive wiped — DBAN, shred, or a clean OS install from the refurb guide. NO donor data, NO old OS, NO leftover files. You are shipping a clean rig, not your old one.
  • [ ] Fresh OS installed with the FED-EDU starter loadout from the sandbox blueprints README — browser, VS Code or Notepad++, Python, Node, and the first-guide bookmark to the playground.
  • [ ] Keyboard, mouse, and cables in the box. A tower with no power cable is a paperweight. Check the box against the prize line in earn-tickets.json — what the ladder promised is what ships.
  • [ ] THE HAND-WRITTEN NOTE inside the box. One paragraph, your hand, your words. Tell the brother what this machine is for. Reference his first guide. This is not optional — the note is half the prize.
  • [ ] A printed copy of the beginner on-ramp README goes in the box. The machine arrives with the first move already on paper.

THE GUARDIAN LINE — UNDER-18 WINNERS

A brother under 18 can win. The machine goes to his parent or legal guardian, and the guardian has to be part of it. This is the line, and it doesn't bend:

  • [ ] Guardian's name and address collected through fed-comm-dm, same as any winner.
  • [ ] Guardian contacted directly — a short plain-talk message: who we are, what the machine is, what the kid is going to build with it, and the URL to the repo so the guardian can see the whole program with their own eyes.
  • [ ] Guardian said yes in writing, in the DM. A "yeah whatever" from the kid is not a guardian yes. The yes comes from the guardian's account or the guardian's verified voice — your call on how you verify, but the record shows a guardian consent.
  • [ ] Label goes to the guardian's name. The machine is addressed to the household, not to the kid alone.
  • [ ] The guardian note in the box explains the program in plain words — what the kid is learning, how the ticket economy works, how to check his progress in the repo. A guardian who understands the program is a guardian who keeps the kid in it.

THE PACK AND SEND

  • [ ] Machine double-boxed or factory-fitted with foam. A refurb tower gets corner foam and the foam card over the CPU cooler if it shipped with one — a loose cooler rips the motherboard out in transit. If you don't know what corner foam is, watch one video, spend the ten dollars.
  • [ ] Laptop or phone kit: bubble wrap, snug fit, no rattle. If you can hear it move, it will break.
  • [ ] Tracking number posted to the winner through fed-comm-dm only. Tracking posted to the public results file with the address parts redacted — just "SHIPPED — tracking sent by DM, ETA in transit."
  • [ ] Cost logged in the Ko-fi transparency post for the month. Shipping money is donated money — the receipts culture applies to the block's money same as a brother's work.

AFTER THE ARRIVAL

  • [ ] Winner posts the arrival receipt to the showcase vault or the boards — a picture of the machine up and running, first boot, or the first guide open on screen. No home exterior, no street signs, no mail with the address showing. The receipt is the machine, not the location.
  • [ ] Arrival logged in the raffle results file — SHIPPED → ARRIVED → BUILDING. The file is the public record that the machine became a builder.
  • [ ] The 30-day check-in scheduled: one DM, one question — "what are you building?" If there's no answer in two weeks, one more try, then the hub lead gets the name for a real-world check if the brother is local to a hub. The machine is the start of a relationship, not the end of one.

IF SOMETHING GOES WRONG

An address lands in a public place: delete the post, request a fresh address in DM, treat the old one as burned, and report it in the help desk issue with the location redacted. The report is "address leaked in X, post deleted, fresh address channel opened" — never repeat the address in the report. That's how a cleanup becomes a second leak.

A package is lost or stolen in transit: the carrier claim is filed by the sender. The winner is not out — he keeps his tickets minus the machine draw, or the tickets return per the raffle lead's call. The next machine in the pipeline goes to him first. Nobody re-draws over a lost box.

A guardian says no after the draw: the machine goes to the next name in the draw's order — the public math gives us the full order, not just the winner. The kid keeps his tickets. The rule is the machine needs a guardian yes, not that a guardian no erases his work.

A winner goes silent with the machine pending: 30 days of silence after two DM tries, the draw rolls to the next name in the order. His tickets stay his — silence is not a crime, life happens, jail happens, housing happens. When he surfaces, he's still in the economy, and the next machine cycle counts him like anyone.

THE CLOSING LINE

Every machine that leaves this block is a bet on a brother. The checklist is how the bet stays clean: the math public, the address private, the guardian in the loop, the note in the box. Run the lines every time. The day you skip the checklist because "it's just a quick one" is the day somebody's front door ends up in a git history that never forgets.

Ship clean. Ship complete. And put the note in the box.
