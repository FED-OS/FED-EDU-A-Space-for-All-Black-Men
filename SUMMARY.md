# 📋 FED-EDU SUMMARY — The One-Page Overview

## What This Is

FED-EDU is a GitHub-based community and educational ecosystem built for all Black men across the globe — every nationality, every background, every circumstance. It translates AI, coding, and tech into plain street terms so that true beginners can grow naturally, build real projects, and ship real products. It is the educational wing of the FED-OS / fedpromptly ecosystem.

**The equation:** FED-EDU = (Urban Dictionary + GitHub) × FED-OS × fedpromptly

## The Problem

There is no global AI, coding, and tech space designed for Black men. Mainstream tech communities are hostile to absolute beginners, culturally irrelevant, and full of gatekeeping. Meanwhile, Black culture powers the internet's biggest platforms while Black men remain locked out of the backend that monetizes it.

## The Solution

A sovereign GitHub organization that combines:

1. **A translation layer** (urban-dictionary/) that decodes tech jargon into street logic
2. **Ready-to-fork project blueprints** (sandbox-blueprints/) for music, sports, media, streaming
3. **Courses built for survival-level hardware** (courses-and-guides/) — EasyTether mastery, no expensive gear required
4. **A marketplace** (hustle-index/) where brothers list services and get hired without background checks
5. **A community layer** (discussion/, wiki/, community-boards/) with flags, daps, and zero elitism
6. **An AI coaching bridge** (fedpromptly-coach/ + prompts/) that answers in plain language
7. **A hardware pipeline** (physical-raffles/) that puts refurbished desktops into the hands of brothers earning them

## Who It Serves

The kid who just got his first bike. The high school baller building a recruiting profile. The young adult who needs a portfolio instead of a paper resume. The returning citizen whose record doesn't matter to a compiler. The older brother proving old dogs learn new tricks. The Jamaican, Haitian, African, British, American brothers. The gay and trans brothers. The homeless brother learning on library Wi-Fi. All Black men, all welcome.

## The Core Philosophy

- **Build first, lecture never.** Day one, you make something real.
- **Tech is real-life Minecraft.** Do whatever you want, build what you want, don't ask permission.
- **No gatekeepers, no background checks.** The machine only asks if the code works.
- **Celebrate the attempts.** First push gets the same dap as first ship.
- **Ownership stays with the builders.**

## The Stack

- **Frontend:** Ultra-lightweight HTML/CSS/JS that loads on EasyTether connections
- **Hosting:** GitHub Pages — free forever
- **Data:** JSON files + optional free-tier Supabase
- **AI:** fedpromptly engine bridge
- **Automation:** GitHub Actions (build.yml, auto_dap.yml, leaderboard_sync.yml)
- **Distribution:** PWA (installable on any device), wrappable to APK
