# 🧠 FED-EDU Prompts Library

**Plain terms:** These are pre-loaded prompts. Copy them, paste them into any AI (fedpromptly.com first, but ChatGPT/Claude/Gemini all work), and the AI instantly becomes a translator, coach, or project generator tuned for the block.

This is the bridge between AI power and brothers who were never supposed to have access to it.

## 🗂️ The Packs

| Pack | File | What it does |
|---|---|---|
| **Street Translator** | [translate_tech_docs.txt](street-translator/translate_tech_docs.txt) | Takes any tech doc/tutorial and rewrites it in plain street terms |
| **Coding Coach** | [explain_like_im_five.txt](coding-coach/explain_like_im_five.txt) | Explains ANY tech concept using everyday life |
| **Coding Coach** | [fix_my_code_step_by_step.txt](coding-coach/fix_my_code_step_by_step.txt) | Debugs broken code WITH you, not FOR you |
| **Project Generator** | [match_my_hobby_to_project.txt](project-generator/match_my_hobby_to_project.txt) | Turns your hobby (rap, ball, gaming, barbering) into a real tech project |
| **Resume Hustle** | [street_to_executive.txt](resume-hustle/street_to_executive.txt) | Turns street-learned skills into corporate-readable resume lines |

## 🎯 How to Use (3 steps, no shortcuts needed)

1. **Open the file** — read it so you know what the AI is being told to do.
2. **Copy the WHOLE thing** — from the first line to the last. It's one complete instruction.
3. **Paste it into your AI** — then follow it with YOUR situation: "Now explain: what is an API" or "Now fix this code: ..."

## ⚖️ The Rules All Prompts Follow

Every prompt in this library obeys the same laws:

- **No jargon without translation.** If the AI says "repository," it must also say "the folder on the internet where your project lives."
- **Never gatekeep.** No "you should already know this." If you should already know it, the coach failed, not you.
- **Real examples.** Every concept gets a life example — corner store, barbershop, hoops, the block.
- **Build, don't just talk.** Every session ends with "your move" — one concrete next action.

## 🏗️ Adding Your Own Prompts

Built a prompt that works? Ship it:

1. Fork the repo, add your file in the right folder (or make a new folder with a README row).
2. Name it in plain terms: `help_me_pass_the_interview.txt` not `int_opt_v2.txt`.
3. PR it with the `#communitybuild` tag — templates live in the root.

**Best prompts get added to the fedpromptly-coach's default library** (see `fedpromptly-coach/context-payload.json`) — that means every brother who uses the coach benefits from what you figured out. That's the multiplier.

## 🧠 Why This Matters

Most AI tools are built for people who already speak tech. The prompts in this folder flip that — they force the AI to meet YOU where you are. It's the difference between a teacher who talks at you and an uncle who sits down next to you.

Kunta Kinte's granddaughter taught him letters so he could write his own name. These prompts teach the machine to speak your language so you can write your own future.

*Same fight. New chains. New literacy. 🏁*
