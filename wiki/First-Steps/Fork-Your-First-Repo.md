# 🍴 Fork Your First Repo — Copy the Block to Your Account

**Plain terms:** "Forking" = making your own copy of somebody's project, connected to the original. You can change ANYTHING in your copy without asking permission. It's the most important button on GitHub and it takes one click.

## 🧠 Why Forking Is Beautiful

Remember mixtapes? A DJ takes somebody's track, remixes it, makes it his own — and the original still stands untouched. That's a fork. You take the FED-EDU code, remix it, ship your version. The original block keeps running; YOUR block runs how YOU want it.

This is also how you contribute back: you build in your fork, then send a "pull request" (a request to merge your changes into the main block) — that's a real contribution, and it earns raffle tickets.

## 🪜 The Steps (5 minutes)

1. **Make sure you're signed in** to your GitHub account.
2. Go to the FED-EDU repo: `github.com/fedpromptly/FED-EDU`
3. Top right of the repo page, click **Fork**.
4. On the fork screen: keep the name (or rename if you want), leave "Copy the main branch only" checked, click **Create fork**.
5. Watch it work for ~10 seconds. Done.

Your URL is now `github.com/YOUR-USERNAME/FED-EDU` — that's YOUR copy. Same content, your workshop.

## 🧭 What You Just Got

Your fork carries the whole block: every guide, every blueprint, the works. You can now:

- **Read & study** — open any file, learn from real code, no permission needed
- **Practice editing** — hit the pencil icon on any file, type, commit. Zero risk: your fork is a playground, not a museum.
- **Start contributing** — make a real change (fix a typo, improve a guide) and send it back as a pull request (see [Push Your First Change](Push-Your-First-Change.md))

## ⚙️ Fork vs. Clone — The 30-Second Difference

You'll hear both words. Simple:

- **Fork** = copy on GITHUB (the cloud). One click. Works from the phone. This is where you START.
- **Clone** = download the files to YOUR computer. Used when you're doing serious work locally with a real code editor. Comes later, when you have a machine and it makes sense (see [BUILD.md](../../BUILD.md)).

Phone-first brothers live in the fork. It's the full experience minus the download.

## ⚠️ Real Talk

- **Your fork does NOT auto-update** when the main block updates. It's a snapshot at the moment you forked. To pull fresh changes later: your fork page → "Sync fork" button → Update branch. Do this before starting any new work so you're not remixing old code.
- **Fork ≠ ownership of the original.** Your fork is yours; the main block stays with the maintainers. If you contribute back via PR and it merges, THAT's when your work becomes part of the main block — and your name lands on the Builders wall (AUTHORS.md).
- **Forking is free, unlimited, and expected.** Every open-source project in the world WANTS to be forked. You're not stealing — you're participating in how the whole internet gets built.
