⬆️ Push Your First Change — The Moment You Become a Builder

Plain terms: A "commit" is a saved change. "Pushing" sends it to your GitHub repo. Your first push is the moment the internet officially records that you BUILD things. There were zero commits with your name before this; after this, there's one. Let's make it count.

🧠 The 60-Second Vocabulary (All Four, Once)

You'll see these four words everywhere. Here's the whole game:

Word Plain meaning Life version
Commit A saved change with your name and a message on it Signing your name on your work
Push Upload your commits to GitHub Mailing the signed work to the shop
Pull Request (PR) "Main block, I made something — check it, maybe merge it" Showing your remix to the OG DJ
Merge Your change officially becomes part of the main project Your verse made the album

That's it. Commit → push → PR → merge. Everything else on GitHub is a variation of these four moves.

🪜 The Steps — Your First Push (All In The Browser, Phone Works)

  1. Open your FED-EDU fork: github.com/YOUR-USERNAME/FED-EDU
  2. Open any file — start with todo.md (the community task board).
  3. Click the pencil icon (top right of the file view) — the file becomes editable.
  4. Make your change: find the - [ ] list, and add one line at the bottom of the open tasks section: - [ ] First push completed by @YOUR-USERNAME — the legend begins
  5. Scroll down to Commit changes:
    • The commit message box: write a real message — add my name to the task board, first push
    • Choose "Commit directly to the main branch" → click Commit changes (green button).
  6. LOOK AT THE FILE. Your line is there. Saved. Timestamped. YOURS.

That was a commit AND a push in one move. The internet now has a record that you build.

🏆 The First PR (The Real Badge)

Your fork's change lives in YOUR copy. Now send it to the main block:

  1. Go to your fork's main page. A banner appears: "This branch is 1 commit ahead of FED-EDU:main" → click Contribute → Open pull request.
  2. GitHub shows a diff (your change highlighted). Click Create pull request.
  3. Fill the title: Add my name to the task board — and in the body, check the box: 🏅 THIS IS MY FIRST PR EVER.
  4. Click Create pull request one more time.

Now the auto-dap bot shows up (it greets every first PR — see .github/workflows/auto_dap.yml), a maintainer reviews, and when it merges: your name enters AUTHORS.md, you earn 5 raffle tickets toward the refurb-PC raffle, and GitHub puts a first-PR badge on your profile. Permanent. Free. Yours.

⚠️ Real Talk

  • Commit messages matter. Future-you is the main reader. add my name to the task board tells future-you everything. asdf tells him nothing. Every commit is a note to the brother you'll be next year.
  • Small commits beat big ones. One change, one commit. It's easier to review, easier to fix if something breaks, and it looks better on your profile graph.
  • It's normal to be nervous. Every brother who ever merged code was once staring at their first commit button. Press it. The block catches people — that's what the six rules are for.

🏁 Your Move

Right now: open your fork, edit todo.md, commit with a real message, open the PR, and check the first-PR box. Ten minutes. At the end of it you'll have a green contribution square on your profile — the first of thousands.
