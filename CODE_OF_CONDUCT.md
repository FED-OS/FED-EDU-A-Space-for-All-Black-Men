# 🛡️ FED-EDU CODE OF CONDUCT — .github Edition

*(The full root `CODE_OF_CONDUCT.md` is the law. This copy lives in `.github/` so it's visible where GitHub surfaces org-level policy. Same rules, same enforcement.)*

## The Six Rules

1. **No question is stupid.** If a brother doesn't know how to create a folder, we walk him through it. Zero judgment.
2. **No jargon without translation.** If you can't explain it in plain terms, you don't understand it well enough to teach it here.
3. **Celebrate the attempts.** First push gets the same dap as first ship.
4. **Zero tolerance for gatekeeping.** Elitism, mocking, downvote culture — banned. This is the anti-Stack Overflow.
5. **Ownership stays with the builders.** Credit where credit is due. Git history is our receipt.
6. **Protect the younger brothers.** Kids are in this space. Keep it safe or be gone — no appeal process.

## Who This Space Serves

All Black men — every nationality, sexuality, age, and circumstance. Allies who genuinely respect the culture and follow the rules are welcome. We check the vibe, not the melanin.

## Enforcement

Violations follow `GOVERNANCE.md`: talk → mediation → sanctions. Rule 6 violations and anything endangering members — instant removal, reported where the law requires. Report privately to any maintainer (see `MAINTAINERS.md`); security matters go through `SECURITY.md`.

## Scope

Everywhere the FED-EDU flag flies: issues, discussions, PRs, DMs through fed-comm, wiki, chapters, and any space where a brother represents this community.

*Each one, teach one.*
