# The Block — Simple GitHub Pages Site

This folder contains a **single-file website** designed to be easy for everyday visitors to understand and easy for you to publish.

## What changed

The original version had 15 tabs, moving text, technical language, fictional activity, and features that suggested a live community, raffle system, or user accounts. The simplified version uses one clear page with five sections:

1. **Start here** helps visitors choose what they need.
2. **Resources** explains the available content in everyday language.
3. **How it works** gives four small, practical steps.
4. **Community** explains how to ask for and offer help.
5. **Support** answers basic questions without pressuring visitors.

The page works on phones and computers. It has no build step, no tracking, no external JavaScript libraries, and no required account.

## Publish on GitHub Pages

1. Create a new repository on GitHub, such as `the-block`.
2. Upload `index.html` to the **top level** of that repository.
3. Open the repository’s **Settings** tab.
4. In the left sidebar, select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/(root)` folder, then click **Save**.
7. GitHub will show the public address once publishing finishes. It is usually similar to `https://your-username.github.io/the-block/`.

## Customize before publishing

Open `index.html` in any text editor and replace these items as needed:

- **The Block** with your own site or community name.
- The project ideas, guides, and templates with your real content or links.
- The Community section with your actual contact method, discussion link, or participation rules.
- The Support section if you add a real way to donate or contribute.

Do not publish fictional member counts, live raffle information, prize listings, winners, or payment claims. If you later run a raffle, paid membership, or donation program, provide accurate rules, costs, eligibility details, and contact information.

## Local preview

Double-click `index.html` to open it in a web browser. Because this is a static page, it can be viewed directly without installing any software.
